## 작업 방식

- 사용자는 **교정대에서 글만 고친다.** 반영·빌드·커밋·푸시·교정대 재배포는 전부 에이전트 몫
- 교정대에 저장된 수정본을 반영한 뒤에는 **db 에서 지운다.** 안 지우면 다음 갱신 때 옛 본문이 되살아난다
- 원본을 바꿨으면 **교정대도 같은 턴에 다시 올린다**
- `git add -A` 를 쓰지 않는다. 경로를 명시해서 stage 한다
- 커밋 메시지는 한국어로 무엇을 왜 바꿨는지 적는다
